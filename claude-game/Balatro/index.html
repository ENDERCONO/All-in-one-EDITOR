⚙ One-time setup needed

Running Balatro in the browser requires two things:

  1. Download the love.js runtime and extract the contents into Balatro/love.js/
    (you need love.js and love.wasm in that folder)
  2. Run package-game.ps1 (right-click → Run with PowerShell) to create game.love
  3. Refresh this page.

Or play the Windows native version:

⬇ Balatro.exe (Windows)
