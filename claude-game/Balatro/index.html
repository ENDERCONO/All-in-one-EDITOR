⚙ ONE-TIME SETUP — BROWSER VERSION

1
Package the game
Download and double-click package-game.bat (button above).
This creates game.love in this folder (~5 MB).
2
Get love.js runtime
Go to github.com/Davidobot/love.js → click the green Code button → Download ZIP.
Extract the ZIP. Inside you will find a folder called dist/ (or the files love.js and love.wasm directly).
Copy both files into a new folder: Balatro\love.js\
3
Reload this page
Click Play in browser above — the game will start loading. First load takes ~15 s (downloads assets).
Folder layout when done:
Balatro/game.love  ·  Balatro/love.js/love.js  ·  Balatro/love.js/love.wasm
