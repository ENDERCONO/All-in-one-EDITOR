# Keyboard shortcuts (Filmora layout)

Owned by `js/app.js`. Shortcuts are ignored while typing in an input.

| Keys | Action |
|---|---|
| Space | Play / pause |
| ← / → | Previous / next frame |
| Shift + ← / → | Back / forward 1 second |
| ↑ / ↓ | Previous / next edit point |
| Home / End | Go to start / end |
| J / K / L | Play backward (step) / pause / play |
| Ctrl + B | Split at playhead |
| C | Blade tool · V Selection tool |
| Delete / Backspace | Delete |
| Shift + Delete | Ripple delete |
| Alt + [ / Alt + ] (also Q / W) | Trim start / end to playhead |
| Ctrl + C / X / V | Copy / cut / paste (paste an image from the clipboard puts it on the timeline at the playhead) |
| Ctrl + D | Duplicate |
| Ctrl + A | Select all clips |
| Ctrl + Z / Ctrl + Y (Ctrl+Shift+Z) | Undo / redo |
| Ctrl + Alt + D | Detach audio |
| Alt + F | Freeze frame |
| M | Add marker |
| N | Toggle snapping |
| Ctrl + = / Ctrl + - | Zoom timeline in / out · Shift + Z zoom to fit |
| Ctrl + I | Import media |
| Ctrl + N / Ctrl + O / Ctrl + S / Ctrl + Shift + S | New / open / save / save as project |
| Ctrl + E | Export |
| Ctrl + T | Add title at playhead |
| Ctrl + Alt + M | New material |
| Alt + Enter | Full-screen preview |
| Ctrl + Alt + K | Show this list |

## Quality-of-life

| Keys | Action |
|---|---|
| Ctrl + Alt + C / Ctrl + Alt + V | Copy / paste effects (color, filters, green screen, hue match, material, blend, opacity, voice + audio fx) |
| Alt + ← / → | Nudge selected clips 1 frame (Shift = 10 frames) |
| Ctrl + ↑ / ↓ | Move selected clips to the track above / below |
| Alt + D | Duplicate selection onto the track above |
| Shift + ↑ / ↓ | Previous / next marker |
| Shift + Home / End | Start / end of the selected clip |
| Ctrl + Shift + K (or B) | Split all tracks at the playhead |
| Ctrl + Shift + Backspace | Close gaps (selected tracks, or all) |
| Ctrl + Shift + M | Mute / unmute clip (Filmora) |
| Shift + R | Reverse clip |
| Ctrl + R | Speed panel |
| Ctrl + L | Loop playback (in/out range, else selection, else everything) |
| X / Alt + X | Set in/out to the selected clip / clear in/out |
| = / - (numpad + / -) | Clip volume ±1 dB · Shift: opacity ±5 % |
| F | Zoom the timeline to the selection |
| ` | Maximize the panel under the mouse (Unreal style) |
| Ctrl + F | Search the library |
| Ctrl + V with a link copied | Download it (YouTube, TikTok, Instagram, X, direct files…) and put it on the timeline at the playhead |
| Ctrl + Alt + S | Snapshot (PNG) |
| Ctrl + Shift + A | Deselect all |
| G | Guides: rule of thirds, title-safe, TikTok/Shorts UI zones (9:16) |
| Ctrl + wheel / middle-drag on the player | Zoom / pan the preview · double-click the backdrop to reset |
| Middle-drag on the timeline | Pan the timeline |
| Right-drag (hold right button) on the timeline | Pan the timeline · a right-click without moving opens the menu |
| Double-click a clip | Playhead to the clip's first frame + open its properties |
| Double-click a title on the player | Edit the text right there (Esc cancels, Ctrl+Enter or click away finishes) |
| Click / drag the ruler while playing | Jump there and keep playing |
| E | Disable / enable the selected clips (skipped in playback and export) |
| F2 | Rename the selected clip |
| Alt + C | Crop and Zoom window (Crop / Pan & Zoom tabs; Space plays, ← → step frames, Enter applies, Esc cancels) |
| Alt + E | Edit properties of the selected clip |
| Ctrl + Alt + → / ← | Rotate 90° clockwise / counter-clockwise |
| Alt + K | Keyframe Graph (curve editor) of the selected clip |
| ◆ next to a property (inspector) | Add / remove a keyframe at the playhead; once a property has keys, any change (slider or on-video handles) keys it at the playhead |
| Keyframe Graph | click / Shift-click / box-select keys · drag = move (snaps to frames, Alt free, Shift one axis) · drag the round handles = tangent · double-click a curve = add key · Delete · F frame all · K add keys at playhead · wheel zoom time · Ctrl/Shift+wheel zoom values · middle/right drag pan · ← → step frames |
| Timeline ◆ on a clip | drag = move that keyframe · double-click = go there · right-click = interpolation / delete |
| Top-left ⛶ button | Whole editor full screen |
| Drop a clip over another (timeline) | Overwrite — the clip underneath is trimmed / split / removed (Filmora) · hold Alt while dropping to slide into a free spot instead |
| Drag a property label in the inspector | Scrub its value (Shift = fine) |
| Right-click the player | Fit / Fill frame / Reset transform / Flip / Guides / Snapshot |
