1 · Home PC (once)
  1. Download the Windows version and open it. Click Install (not just run) so it starts with Windows and works even at the login screen.
  2. Open Settings → Security, click Unlock security settings, then Set permanent password. Use a long, unique password.
  3. Note the ID shown in RustDesk's main window and save it under My PCs on this page.
  4. Keep the PC on (Windows Settings → System → Power: sleep "Never" while plugged in).
Anyone with your ID and password can control the PC. Never share the password, and turn it off in RustDesk if you suspect it leaked.
2 · Connect from phone or another PC
  1. No install: press Web next to your PC below (copies its ID and opens RustDesk's browser client in a new tab), paste the ID and connect.
    Or install RustDesk on the device (Android: F-Droid or the APK; iPhone: App Store) and press Open.
  2. Enter the permanent password. Tick Remember password on your own devices only.
Smoother picture: in a session open the toolbar → Display → codec H265 or AV1 (if both devices support it), and image quality Optimize reaction time. On the same Wi-Fi, enable Settings → Security → Enable direct IP access and connect to the PC's local IP.
